# CUGB大一一年指南：一个大二学生的信息差、试错与思想札记

一个按原目录结构浏览资料的静态在线文件夹，采用蓝白地质视觉风格。

> 本项目为学生个人整理与设计，并非中国地质大学（北京）官方网站或官方资料库。

## 本地预览

直接打开 `index.html` 即可浏览。网站不依赖后端服务，也不会分析文档内容。

## GitHub Pages

仓库包含大量原始图片和课件。为避免 Pages 成品站点超过体积限制，自动发布流程只部署轻量网页，资料文件通过仓库原始文件地址访问。

首次使用时，请在仓库的 **Settings → Pages → Build and deployment** 中将 Source 设为 **GitHub Actions**，随后重新运行 `Deploy static archive to GitHub Pages` 工作流。

## 内容与隐私说明

公开发布前，请确认文档、图片、课件和音频均已获得必要授权，并检查姓名、学号、人脸、联系方式、定位信息等个人信息。代码授权与资料内容授权应分别说明。
